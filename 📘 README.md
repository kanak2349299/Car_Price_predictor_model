# **🚗💰 Car Price Prediction using Machine Learning**

> 🎯 Predict the selling price of used cars using Machine Learning Regression Models.

---

# **🌟 Project Overview**

This project predicts the **Selling Price** of used cars by analyzing various features such as:

🚘 Car Name  
💵 Present Price  
🛣️ Kilometers Driven  
⛽ Fuel Type  
🏪 Seller Type  
⚙️ Transmission  
👤 Number of Owners  

The project includes complete **Data Preprocessing**, **Exploratory Data Analysis (EDA)**, **Model Training**, **Model Evaluation**, and **Model Comparison**.

---

# **📂 Dataset**

📌 **Source:**
 🔗[link](https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars)

📊 **Number of Records:** 301

🎯 **Target Variable:** Selling_Price
